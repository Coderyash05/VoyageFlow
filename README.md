# VoyageFlow
VoyageFlow is a comprehensive client-side web application that simulates a complete travel planning journey. This interactive platform guides users through registration, destination exploration, trip customization, and booking confirmation - all within a single, seamless interface.

Key Features
1. User Registration & Validation
Clean, responsive registration form with real-time validation

Phone number validation: Exactly 10 digits required

PIN code validation: Exactly 6 digits required

Email validation: Standard email format verification

Custom success modal with smooth page transitions

2. Destination Exploration
Five stunning destinations: Paris, Tokyo, Rome, Bali, and New York

Sticky navigation tabs for easy section switching

Smooth scrolling between destination sections

Rich content with detailed descriptions and traveler testimonials

Visual gradient placeholders representing each location's aesthetic

3. Interactive Trip Calculator
Four customizable categories:

Travel Options (Economy, Business, First Class)

Accommodation (Budget Hotel, Luxury Resort, Vacation Rental)

Food Packages (Basic Meals, Gourmet Dining, Food Tour)

Activities (City Tour, Adventure Package, Cultural Experience)

Real-time price calculation with instant updates

Visual feedback with hover effects and transitions

4. Booking Confirmation
Animated success confirmation with bounce effect

Comprehensive review section showcasing satisfied travelers

Start over functionality to begin a new journey
